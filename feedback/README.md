# Экспорт обратной связи

`latest.json` в этой папке обновляется автоматически workflow'ом
`.github/workflows/fetch-feedback.yml` — забирает содержимое таблицы
`dev_feedback` из продовой БД через защищённый админ-эндпоинт и коммитит
сюда как обычный файл.

Зачем: у ассистента (Claude), который ведёт разработку этого проекта, нет
прямого сетевого доступа к домену Render из своей рабочей среды и нет
возможности слать запросы с кастомными заголовками через доступные ему
инструменты чтения веб-страниц. Но он свободно читает файлы в этом
репозитории через `git pull`. Workflow с полным доступом в интернет
(GitHub-раннер) выступает мостом между приватным API и обычным файлом
в git — так ассистент может сам, по запросу, инициировать обновление
через GitHub API (тем же токеном, которым пушит код) и затем прочитать
результат, не дожидаясь, пока кто-то вручную скопирует данные.

Не редактировать `latest.json` вручную — перезапишется при следующем
запуске workflow.
